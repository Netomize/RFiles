This folder contains the PacketSmith [Yara-X detection module rules](https://github.com/Netomize/RFiles/blob/main/cve_2026_16723/fastjson_rce_cve_2026_16723.yar) and a [pcap](cve_2026_16723/cve_2026_16723_deserialization_rce.pcap) for the [CVE-2026-16723](https://nvd.nist.gov/vuln/detail/CVE-2026-16723) vulnerability in the [FastJson library](https://github.com/alibaba/fastjson), "*a Java library that can be used to convert Java Objects into their JSON representation*". Moreover, the detection results in JSON [yara_dte_2026_05_14_10_34_39.json](https://github.com/Netomize/RFiles/blob/main/cve_2026_16723/yara_dte_2026_07_28_21_10_11.json) were made available for download.

For more info, check the article [FastJson 1.2.83 Remote Code Execution](https://fearsoff.org/research/fastjson-1-2-83-rce) by [FEARS OFF](https://fearsoff.org/).
